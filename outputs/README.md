# Output provenance

- v4/verdict_v4.json is the canonical machine-readable result for the
  corrected 15-item ledger.
- v4/claim_matrix.csv is the compact claim/status/passed summary.
- v4/figures/ contains the five generated figures used by the v4 evidence
  pages.
- verify_run.log preserves the recorded grouped-check output.
- verdict.json is a compatibility copy retained from the v4 package; consult
  v4/verdict_v4.json for the canonical schema.

The outputs are evidence artifacts, not proof certificates. Interpret each
status together with the scope and limitations in the root README and
AUDIT_REPORT.md.
